# Rusher Utils

Hello, this plugin contains some small features for rusherhack. Currently, it only has the HighJump (Shulker) module.

If you are wondering what the HighJump module does: when you are playing on servers like 2b2t, if you jump while you are near shulker boxes or shulker mobs, it launches you high into the air. This is especially useful when you are flying with an elytra, because you can easily go up thousands of blocks very fast (well, currently the 2b2t bypass is broken because I'm a dumbass and couldn't bypass their current anti-cheat, but if you know how to fix this shit feel free to open a PR).

For now this is the only module, but I am planning to add new modules and more features to this project in the future.

To install it, just put the jar file from the build folder into your rusherhack plugins folder.
