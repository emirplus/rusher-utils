#Rusher Utils

This plugin adds the HighJump (Shulker) module to Rusherhack. When you jump near shulker boxes or shulker mobs, it launches you high into the air for easy elytra takeoffs. The Grim anti-cheat bypass is currently broken because I lack the brain cells to bypass it right now, so feel free to open a pull request if you actually know how to fix it. More features will be added in the future when motivation allows. To install, put the jar file from the build folder into your plugins folder.
